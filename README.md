# LeetCode Cheatsheet

A clean, mobile-friendly edition of [jwl-7's LeetCode Cheatsheet](https://github.com/jwl-7/leetcode-cheatsheet).

The GitHub Pages workflow builds the original MIT-licensed source and applies the local design overrides. Original algorithm examples and all language templates remain unchanged.

## Deployment

Go to **Settings → Pages → Build and deployment → GitHub Actions**, then run **Actions → Deploy cheatsheet → Run workflow**.

Website: https://froehlich99.github.io/leetcode-cheatsheet/

## Development

The workflow acts as a reproducible upstream build. The UI overrides live in `site/clean.css` and `site/patch.py`.
